# CRUD-RAG 检索与分块测评 · 通俗版

> 目标读者：不需要懂 RAG 细节的同事/朋友。前两轮报告见
> [../通俗版.md](../通俗版.md)。这一轮我们干了一件升级的事：**把系统放到
> 行业公认的比赛卷子上考了一次，而且全程用真实模型跑**。

## 一、这轮和前两轮有什么不一样

前两轮我们测分块，像是在自家训练场考科目二：题目是权威题库（CMRC 2018）
+ 我们自己出的业务题，但**考官只看"关键词检索"这一项技能**——因为真实
模型调用要花钱花时间，当时的纪律是零模型调用。

这一轮授权到位（可以用真实模型了），于是直接报了**行业正式考试**：
CRUD-RAG——中文 RAG 领域被引用最多的公开基准之一（IAAR-Shanghai 发布，
论文编号 arXiv:2401.17043）。它的题库里是 2023 年之后的中文新闻，考法是
"给你一堆新闻，回答一个问题，看你能不能把对的那篇新闻找出来"。

我们用了它的一个子集：

| 部分 | 数量 | 通俗解释 |
| --- | --- | --- |
| 新闻文档 | 3,000 篇 | 相当于一个中型资料库，里面混着"答案所在"和 2,999 篇干扰项 |
| 标注问题 | 86 道 | 每道题都标好了"哪篇新闻能回答它"，还附了参考答案 |

另外，这次检索的每一步都用的是**真实模型**（本地部署的 bge-m3 向量模型、
bge-reranker-v2-m3 重排模型），一共算了几十万个向量——这就是前两轮做
不了这场考试的原因。

## 二、怎么考的

我们让系统用**四种姿势**做同一张卷子，姿势之间只差"开了哪些环节"：

1. **只翻关键词**（BM25）：像查字典，按词对词匹配；
2. **只靠语义**（向量检索）：理解"意思相近"也算对；
3. **两条腿一起上**（混合检索）：现行生产配置；
4. **两条腿 + 精读教官**（混合 + 重排）：再用一个更聪明的模型把最像的
   往前排——这是生产系统的完整形态。

同时，分块大小试了 128 / 256 / 512 / 1024 四档（现行 512），相当于把
"资料剪多碎"换了四种剪法重考。

**防作弊措施**：我们另外搭了一个 12 个文件的小考场，让"正式系统"和
"快速考试系统"做同样的 10 道题对答案——**10 道全对上**，证明考试系统
量的就是线上跑的那个东西。

## 三、考出了什么

### 3.1 大快人心：前 5 名全对

**86 道题、16 种姿势组合，"正确新闻出现在前 5 名"的比例全部是 100%。**
也就是说，现在的系统架构在这张公认考卷上**已经考到满分了**——512 的
分块参数不用动，两种检索腿一起上的设计被证明确实稳。

### 3.2 差别藏在细节里：一道"刁钻题"的故事

86 道题里有 85 道，所有姿势都能稳稳把正确答案排第一名。唯一的例外是
一道"地狱难度"的题，它同时问了**日期、哪五个部门、通知全名、为了哪个
领域**四件事。这道题的成绩单：

| 姿势 | 正确新闻排第几 |
| --- | --- |
| 只翻关键词 | 第 4 |
| 两条腿一起 | 第 4 |
| **+ 精读教官（重排）** | **第 2** |

重排模型的价值就体现在这：**简单题它不需要出手，难题它兜底。**

### 3.3 两个"差点跟风"的优化，测完决定不跟

这轮做之前我们调研了 GitHub 上的主流做法，有两个热门技巧专门做了对照
实验：

- **把资料剪得更碎**（128 小块）：网上很多教程推荐。实测：块数变成
  5 倍（向量化成本、存储、检索全变 5 倍），成绩一分没涨。**不跟。**
- **给每块资料自动贴关键词标签**（RAGFlow 的"自动关键词"功能）：
  实测：成绩逐位相同，一分没涨。原因想明白了——关键词本来就是这个块里
  出现过的词，检索时早就匹配得上，贴个标签属于重复劳动。**不跟。**

> 这两条"负结果"可能是这轮报告最值钱的部分：网上流行的方法，在自己
> 的数据上测过再决定用不用，和直接抄，是两种工程师。

### 3.4 和官方论文对了个账

CRUD-RAG 官方论文说"单文档问答偏好小块（128 字符）"，我们测出来小块
没优势——**看起来矛盾，其实都对**：官方比的是"回答得好不好"（生成端），
我们比的是"找得准不准"（检索端）；而且我们的系统本来就有"小块检索 +
大块喂模型"的两层设计，小块的红利早就被吃掉了。敢在报告里写"官方结论
在我们的场景下不成立"，比照抄结论更有说服力。

## 四、结论一句话

**现行的分块参数（512/64）和检索架构（关键词+向量+重排）在行业公认
基准上已经考到满分，一个参数都不用改；重排的价值在难题上兜底；两个
流行优化技巧实测无效，拒绝跟风。** 下一步去更难的考卷：多跳问题和
"答案写得好不好"的端到端测试（见同目录其他报告）。
