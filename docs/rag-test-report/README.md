# RAG 分块策略测试报告

本目录是一次完整的分块策略测评产出，回答一个问题：**这套 RAG 的分块参数
（块大小 512 / 重叠 64 / 每父块 12 行）和分块策略（结构感知 + 父子双层）
是抄来的默认值，还是被数据验证过的？**

## 结论速览

| 问题 | 答案 |
| --- | --- |
| 512/64/12 要不要改 | **不改**——网格扫描显示它就是本任务的最优档（详见报告） |
| 256（更小的块） | 召回少 1 例，子块数量 +71%（embedding 成本同步 +71%），不值 |
| 768（更大的块） | 召回持平，但句子被拦腰切断的比例从 4% 涨到 13%，引用质量受损，不值 |
| 重叠（overlap） | 0/32/64/128 差异 ≤1 例（噪声级），保留 64（bge-m3 官方建议 + 边界保险） |
| 每父块行数 | 对检索召回零影响，12 是「上下文完整 vs 引用粒度」的平衡点，保留 |
| 朴素定宽切分 vs 现有策略 | 召回打平，但定宽切分丢失引用定位、表头绑定、结构元数据——不换 |
| 中文逗号加入分隔符 | 实测零收益，不采纳（避免无依据改动） |

## 如何复现

```bash
# 首次运行会从 GitHub 下载 CMRC 2018 dev 集（3.3MB，缓存到 data/rag-eval/）
python scripts/eval_chunking.py --out docs/rag-test-report/data/chunking-sweep.json
```

全程 **不调用任何真实模型**（BM25-only 评测，tokenizer 用本地 bge-m3 权重目录），
语料构建用 SHA-256 确定性采样，任何机器上重跑结果一致。

## 测评集构成（一句话版）

1. **CMRC 2018**（哈工大&讯飞，EMNLP 2019，CC BY-SA 4.0）：240 篇标准段落 +
   60 篇五段拼接的长文压力段落 → 210 道带标准答案的中文阅读理解题
2. **业务仿真集**：报销制度 docx + 报销明细 xlsx + 60 行大表 → 28 道业务问句
   （含口语化问法）
3. **对抗结构集**：堆叠表/宽表/超长段落 → 只测结构合规（块超预算率、拦腰切断率），
   不进检索排名
